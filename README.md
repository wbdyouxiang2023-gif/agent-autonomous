# Agent Autonomous Workspace

Self-driving AI development system with autonomous goal execution.

## Features
- Autonomous task generation and execution
- Real-time dashboard with system metrics
- Go CLI tool + Python Gradio interface
- GitHub Actions CI/CD pipeline

## Quick Start
```bash
# Run dashboard
python3 app.py

# Use CLI
./todos add "new task"
./todos list
```
